## Built-in Objects and Methods Used

### Date Object
- `new Date()` - Creates an object with the current date.
- `getMonth()` - Gets the current month.
- `getDate()` - Gets the current day.
- `getFullYear()` - Gets the current year.

### Number Object
- `Number()` - Converts a value into a number.
- `Number.isNaN()` - Checks if a value is NaN.
- `Number.isInteger()` - Checks if a value is an integer.
- `toFixed(2)` - Formats a number to two decimal places.

### Other Methods and Properties
- `String()` - Converts a value into a string.
- `padStart()` - Adds leading zeros to the month and day.
- `document.querySelector()` - Selects an HTML element.
- `innerHTML` - Displays and updates content on the webpage.
